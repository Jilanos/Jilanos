# Paul Mondou

I build local-first engineering tools that turn complex operational data into reliable, inspectable workflows.

My projects span CAN diagnostics, electrical-system design, personal analytics, and human-supervised developer automation. I care about privacy boundaries, reproducible tests, and interfaces that help people make decisions rather than hide them.

## Selected Projects

- [CanTraceDiag](https://github.com/Jilanos/CanTraceDiag) [![CI](https://github.com/Jilanos/CanTraceDiag/actions/workflows/ci.yml/badge.svg)](https://github.com/Jilanos/CanTraceDiag/actions/workflows/ci.yml): turns CANalyzer `.asc` traces and DBC files into a local diagnostic workstation with plots, cursors, trace inspection, and a tested Python/FastAPI backend.
- [Electrical Plan Editor](https://github.com/AlexAgo83/electrical-plan-editor): major collaborative contribution to a browser-based electrical-plan editor with live deployment, CI, and extensive automated tests.
- [Cashflow Lab](https://github.com/Jilanos/cashflow-lab): explores personal cashflow scenarios in a local-first React/TypeScript app backed by browser-side SQLite and a focused Vitest suite.
- [World Cup Predictor](https://github.com/Jilanos/world_cup_predictor): models football tournament outcomes with reproducible simulations, backtests, and Python tests.
- [Scrappy](https://github.com/Jilanos/scrappy): reviews job offers locally, explains fit and gaps, and keeps the evaluation workflow inspectable through Python tests.
- [Orchestia](https://github.com/Jilanos/orchestia): documents and validates a human-supervised operating model for AI-assisted software delivery, with executable workflow checks.

## How I Build

- Local-first by default, with clear boundaries around private or customer data.
- Reproducible setup, automated tests, and small validation loops before broader changes.
- Automation under human supervision, especially where tools can affect real work.
