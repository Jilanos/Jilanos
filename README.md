# Paul Mondou

I build local-first engineering tools that turn messy operational data into usable workflows.

Current focus:
- Python and TypeScript applications for industrial diagnostics, electrical tooling, personal analytics, and AI-assisted development workflows.
- Local data processing with clear privacy boundaries, reproducible tests, and practical user interfaces.
- Human-supervised automation: useful tooling first, autonomy only where it is bounded and reviewable.

Selected projects:
- [CanTraceDiag](https://github.com/Jilanos/CanTraceDiag): local CAN trace analysis and DBC decoding with a Python backend and web UI.
- [Cashflow Lab](https://github.com/Jilanos/cashflow-lab): local-first personal finance planning with React, TypeScript, and browser-side SQLite.
- [Scrappy](https://github.com/Jilanos/scrappy): explainable local job-offer review and skill-gap analysis.
- [Orchestia](https://github.com/Jilanos/orchestia): a human-supervised operating model for AI-assisted software development.
